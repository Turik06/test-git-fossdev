# NDFL Calculator Toolki

### Описание решения
Проект представляет собой Python-библиотеку для расчета налога на доходы физ. лиц (НДФЛ).
Проект является **by-design** изолированным: все зависимости и сборка происходят строго в виртуальном окружении.

### Установка пакета из TestPyPI
Пакет опубликован на тестовом сервере PyPI. Установка выполняется следующей командой:

```bash
pip install --index-url https://test.pypi.org/simple/ ndfl-calculator-toolkit
```
