# NDFL Toolkit

Python-библиотека для расчета налога на доходы физических лиц (НДФЛ) по прогрессивной шкале в соответствии с актуальным законодательством РФ.

## Налоговая шкала

Библиотека автоматически определяет налоговый диапазон и применяет соответствующую ставку:

| Годовой доход | Ставка | Формула расчета |
| :--- | :--- | :--- |
| До 2,4 млн руб. | 13% | 13% от дохода |
| 2,4 – 5 млн руб. | 15% | 312 000 + 15% с суммы превышения |
| 5 – 20 млн руб. | 18% | 702 000 + 18% с суммы превышения |
| 20 – 50 млн руб. | 20% | 3 402 000 + 20% с суммы превышения |
| Свыше 50 млн руб. | 22% | 9 402 000 + 22% с суммы превышения |

## Использование

Импортируйте функцию `calculate_ndfl` и передайте годовой доход в рублях:

```python
from ndfl_toolkit import calculate_ndfl

# Доход 2 000 000 руб. -> ставка 13%
tax = calculate_ndfl(2_000_000)
print(tax)  # 260000.0

# Доход 10 000 000 руб. -> ставка 18%
tax = calculate_ndfl(10_000_000)
print(tax)  # 1602000.0

# Доход 60 000 000 руб. -> ставка 22%
tax = calculate_ndfl(60_000_000)
print(tax)  # 11602000.0
```

## Как это работает

Алгоритм использует обратный проход по порогам налогообложения, что позволяет избежать вложенных условных конструкций и делает код компактным и легко расширяемым при изменении законодательства.

```python
tiers = [
    (0, 0, 0.13),
    (2_400_000, 312_000, 0.15),
    (5_000_000, 702_000, 0.18),
    (20_000_000, 3_402_000, 0.20),
    (50_000_000, 9_402_000, 0.22)
]

for start, addition, taxrate in tiers[::-1]:
    if income > start:
        return (income - start) * taxrate + addition
```

При совпадении условия `income > start` функция мгновенно возвращает рассчитанную сумму. Это обеспечивает линейную сложность O(N), где N — количество ступеней.

## Тестирование

Проект покрыт модульными тестами с использованием `pytest`.

- Проверены типовые значения для всех пяти диапазонов.
- Тест на отрицательный доход помечен как `@pytest.mark.xfail`, так как функция намеренно выбрасывает `RuntimeError` при некорректных входных данных.

Запуск тестов:
```bash
make test
```

## API Reference

### `calculate_ndfl(income)`

Рассчитывает сумму НДФЛ на основе годового дохода.

**Параметры:**
- `income` (int | float): годовой доход в рублях.

**Возвращает:**
- `float`: рассчитанная сумма налога в рублях.

**Исключения:**
- `RuntimeError`: вызывается при отрицательном доходе или некорректных входных данных.

## Масштабируемость

Для изменения налоговой шкалы достаточно отредактировать список `tiers` в начале функции. Формат кортежа:
`(порог_дохода, накопленная_сумма_налога_на_предыдущих_ступенях, ставка)`.
