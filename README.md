# Make

## Структура проекта

```text
task/
├── src/                # Исходный код приложения
│   ├── app.py          # Точка входа (Задание 1)
│   ├── calc.py         # Модуль для проверки типов (Задание 3)
│   ├── example.py      # Модуль для проверки стилей (Задание 4)
│   └── service.py      # Модуль для проверки зависимостей (Задание 2)
├── README.md           # Детальный технический отчет (статья по заданиям 1-5).
├── Makefile            
├── requirements.txt    # Список внешних зависимостей
└── .gitignore          # Исключение артефактов сборки (.venv, кэши)
```

### Что происходит под капотом 

1. **Подготовка окружения:** Проверка флага установки. Если `.venv` нет, Make сам его создаст и установит пакеты из `requirements.txt`.
2. **`typecheck`:** Запуск `mypy` для статического анализа типов.
3. **`lint`:** Запуск `pycodestyle` для проверки стиля (PEP 8).
4. **`check-deps`:** Запуск `deptry` для выявления забытых или неиспользуемых библиотек.

## Точка входа

Для проверки работоспособности проекта не нужно вручную активировать окружения или вспоминать команды линтеров. Достаточно использовать один высокоуровневый target:

```bash
cd task
make check
```
