# NDFL
Библиотека для расчета налоговых вычетов

Проект использует `make` для управления проектом.

## Правильный порядок команд `make`:
- `make venv` - Создает окружение и устанавливает туда все нужные зависимости
- `make test` - Автоматически тестирует все нужные файлы .py
- `make build` - Собирает проект
- `make publish` - публикует проект на test.pypi


## Структура проекта

`/tdd/` - Корневая папка проекта
`/tdd/docs/` - Документации к проекту
`/tdd/tests/` - Модульные тесты
`/tdd/src/` - Исходный код проекта
`/tdd/Makefile` - Точка входа для разработки
`/tdd/pyproject.toml` - Конфигуратор проекта
`/tdd/requiremets.txt` - Список зависимостей
`/tdd/README.md` - Подробное описание проекта
