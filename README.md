# Make

## Структура проекта

task/
├── Makefile        — Конфигурация автоматизации (таргеты).
├── README.md       — Детальный технический отчет (статья по заданиям 1-5).
├── requirements.txt — Список внешних зависимостей проекта.
├── .gitignore      — Правила исключения временных файлов и артефактов.
└── src/            — Директория с исходным кодом.

## Точка входа

Для проверки работоспособности проекта не нужно вручную активировать окружения или вспоминать команды линтеров. Достаточно использовать один высокоуровневый target:

```bash
cd task
make check
```
